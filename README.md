不會馬上消失，但有一些時間線要搞清楚（以下規則於 2026 年 3 月起正式生效）：

**會員到期後的狀態變化：**
- **即刻起**：無法上傳新檔案或新增雲端下載任務（如果使用空間超過 6GB）
- **到期後 7 天**：無法在線播放影片，本地下載速度限制到 100 KB/s
- **持續超額狀態超過 6 個月**（含 2 個月寬限期）：系統開始從最舊的檔案往後逐步刪除

所以如果你打算暫停不用，**記得先把重要檔案下載回本機**，或把雲端使用量清理到 6GB 以下，就不會有任何問題。
